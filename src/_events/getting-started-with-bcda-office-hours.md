Join the Beneficiary Claims Data API (BCDA) team for an introduction to BCDA v3. Learn more about accessing Medicare Claims data using BCDA and get tips on how to get started with BCDA. 

Following a 20 minute overview of BCDA, the BCDA team will be available to answer your questions including those about v3 and any other topics related to BCDA.

All attendees and questions are welcome, however the presentation content will be oriented towards new BCDA users.
